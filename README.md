Mobile Sales Dashboard
Project Overview

The Mobile Sales Dashboard is an interactive data visualization project designed to analyze and monitor mobile phone sales performance. It provides key insights into sales trends, revenue, customer behavior, and product performance using dynamic charts and KPIs.

Objectives:
Analyze overall mobile sales performance

Track revenue, profit, and quantity sold

Identify top-selling brands and models

Understand customer purchasing trends

Provide actionable insights for business decisions

Key Features:
Sales Overview – Total revenue, profit, and units sold

Top Brands & Models – Best-performing products

Region-wise Analysis – Sales distribution across locations

Time-based Trends – Monthly/Yearly sales trends

Customer Insights – Buying patterns and preferences

Interactive Filters – Dynamic slicers for better analysis
